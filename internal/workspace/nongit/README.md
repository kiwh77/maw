# internal/workspace/nongit

非 Git 项目的受管任务目录。为独立文档／调研任务提供与 Git 工作空间**同一套占用约束**，
只是目录形态不同：没有分支、没有基线提交，所以校验换成「产物根仍在且仍不是 Git」。

## 目录形态

```text
<非 Git 产物根>/                  # 调用方显式给出，必须已存在，不代建
  .maw-work/
    <agent>/                      # 默认任务目录：同一 Agent 复用，目录数不随任务数增长
      ...                         # 任务产物，复用时不清理、不覆盖
```

显式 `Path` 可以指到产物根下的具体任务目录（例如 `reports/q3-draft`），但**不得越出产物根**。

## 判定规则

| 情形 | 结果 |
| --- | --- |
| 产物根缺失／不是目录／相对路径 | `invalid_spec`：非 Git 没有可推断的根，必须显式给出已存在的绝对路径 |
| 产物根（或任务目录）落在任何 Git 工作树里 | 拒绝并指回 `internal/workspace`：仓库内文档要走 Git 工作空间才有基线可回溯 |
| 显式 `Path` 不在本产物根下 | 拒绝：跨工程路径会把两个工程的产物写进同一个目录 |
| 运行仍占用（阶段非终态／核实 unknown／failed·cancelled 但进程未确认停止） | `E240`，目录不会被创建，也不会被碰到 |
| 运行已结束但 `delivery_frozen = false` | `E240`：未知执行与待冻结结果继续占着原目录 |
| 运行已结束且产物已冻结，目录已存在 | 原地复用：不清理、不重置，已有产物逐字节保留，列出保住了哪些条目 |
| 路径被一个同名文件占着 | 冲突：不覆盖、不删除 |

失败一律返回 `*nongit.Failure`（`AsFailure` 取回），带 `Stage`、动工前现场 `Before`
与失败时刻现场 `After`；本包从不为了「收拾干净」而删任何东西。

## 两条容易踩的边界

- **不做向上搜索**。Git 版可以从子目录 `rev-parse` 到仓库根，非 Git 没有这个锚点；
  猜一个根等于把产物放到错的地方，所以只认显式 `Root`（`Root` 为空时用 `Cwd` 原样顶上）。
- **复用不是重建**。目录里可能就躺着上一题待验收的产物；本包只在目录不存在时 `MkdirAll`，
  存在时一个字节都不写。清理属于验收之后（`internal/verification/nongit`），不在这里。

## 验证

```sh
CGO_ENABLED=0 go test ./internal/workspace/nongit -count=1
```

用例覆盖：仓库根／仓库子目录被拒、跨产物根被拒、别名路径收敛、占用状态矩阵（运行中／
核实未知／停止未确认／待验收／已冻结）、重复准备幂等、复用不改产物、同名文件不被覆盖、
产物根消失不代建、两个产物根互不干扰。
