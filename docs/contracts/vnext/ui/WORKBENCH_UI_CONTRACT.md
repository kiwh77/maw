# Workbench 视觉与交互契约（vnext / UI）

| 项 | 值 |
| --- | --- |
| 契约版本 | v1（VN-021 冻结） |
| 状态 | Frozen |
| 适用范围 | `docs/contracts/vnext/ui/**` 下的新增页面与组件 |
| 实现参照 | `internal/board/page.html` 的 `:root` 与既有 Board 布局 |
| 上游设计 | `docs/BOARD_DESIGN.md` |
| 验证命令 | `python3 -m unittest discover -s docs/contracts/vnext/ui -p 'test_*.py'` |

本契约只冻结既有 Workbench 的视觉与交互语言，供后续新增页面复用。它不重新设计品牌，不改页面代码，也不从截图取色。

## 1. 不变量

- 不新设页面皮肤：所有 vnext 页面共用同一套 token、同一套间距与同一套状态词汇。
- 不引入第二套 token 体系；`internal/board/page.html` 的 `:root` 是颜色与圆角的唯一实现参照。
- 不引入字体／图标 CDN，只用系统字体栈；图标使用文本符号或内联 SVG，不引第三方图标库。
- 不新增状态、泳道或页面级主题；新增前必须先更新本契约与服务端枚举。

## 2. 颜色 token

颜色名固定，明暗两套共用语义与结构。默认跟随系统（`prefers-color-scheme`），右上角可切 System / Light / Dark，选择存入 `maw-theme`；页面不得自带独立主题。

| Token | Dark | Light | 职责 |
| --- | --- | --- | --- |
| `--bg` | `#141618` | `#f7f8f9` | 主工作区背景（石墨灰／纸白） |
| `--panel` | `#191c1f` | `#eef1f3` | 侧栏、筛选区、抽屉、表单控件底色 |
| `--card` | `#202427` | `#ffffff` | 可打开的任务对象 |
| `--hover` | `#272c30` | `#e4e9ec` | 行／导航悬停底色 |
| `--line` | `#2d3338` | `#dce1e5` | 分隔线、卡片边缘、表格行线 |
| `--line-strong` | `#414a51` | `#c1cbd2` | 泳道顶线、抽屉左边界、键盘提示描边 |
| `--text` | `#e6eaed` | `#20282f` | 标题与正文 |
| `--muted` | `#9ba5ad` | `#5b6871` | 标签、次要信息、来源标识 |
| `--faint` | `#7d8992` | `#6b7882` | 编号、符号等装饰信息 |
| `--accent` | `#9cdbb0` | `#267044` | 信号绿：选择态、主操作、进度、完成 |

| `--scrim` | `#0007` | `#17232e38` | 抽屉遮罩 |

## 3. 形状、字级与密度

- 圆角：表单、按钮、卡片、空态统一 `6px`（`--radius`）。只有不超过 20px 的图标按钮、复制小按钮可用 `4px`，键盘提示可用 `3px`。
- 字级：只允许 `22px`（页面标题）、`18px`（抽屉或面板标题）、`13px`（正文，默认）、`12px`（卡片标题、键值、表格内容）。新增页面不得再引入 10px／11px 正文；这两个尺寸只保留给既有 Board 的高密度元数据（mono 徽标、Agent 状态），不得复制到新页面。
- 行高：正文 `1.5`，卡片标题 `1.45`，抽屉标题 `1.5`。
- 间距：页面左右边距 `28px`（`28px`），区块与列表间距 `16px`（`16px`）；卡片内边距 `12px`；表格行高不低于 `36px`。
- 控件高度：标准 `32px`；顶部栏主题选择器这类紧凑控件 `28px`，不得更小。
- 字体：正文系统 sans（含 `PingFang SC` / `Microsoft YaHei` 回退）；ID、路径、命令、数字用 mono。字号与字族不得改用远程字体。

## 4. 状态词汇与泳道

状态键为小写 snake_case，写死 11 个，不得同义改写。中文标签与泳道归属如下；颜色职责见第 5 节。

| 状态 | 中文标签 | 泳道 | 颜色职责 | 说明 |
| --- | --- | --- | --- | --- |
| `backlog` | 待排期 | 待处理 | `--muted` | 尚未进入调度 |
| `ready` | 可领取 | 待处理 | `--muted` | 可被 Agent 领取 |
| `claimed` | 已领取 | 执行中 | `--warn` | 已绑定 Agent，尚未开工 |
| `in_progress` | 进行中 | 执行中 | `--warn` | 正在执行 |
| `self_check` | 自检中 | 执行中 | `--muted` | 执行者自检，不提示人工 |
| `in_review` | 评审中 | 评审与合并 | `--muted` | 等待评审结论 |
| `merging` | 合并中 | 评审与合并 | `--muted` | 正在合入主干 |
| `conflict` | 冲突 | 需处理 | `--danger` | 写盘或合入冲突 |
| `blocked` | 阻塞 | 需处理 | `--danger` | 无法继续，需人工介入 |
| `done` | 已完成 | 已结束 | `--ok` | 已完成并合入 |
| `cancelled` | 已取消 | 已结束 | `--muted` | 主动取消 |

泳道固定五个：`queued` 待处理、`running` 执行中、`integrating` 评审与合并、`attention` 需处理、`finished` 已结束。泳道内为空时不占位；`attention` 为空时整列隐藏；未知状态单独成列，不猜测归并。列内独立滚动，只有任务流区域在窄屏横向滚动。

## 5. 颜色职责：状态与来源

- 状态只用语义色，且只表达状态：`--muted` 待办、`--warn` 需关注、`--danger` 异常、`--accent`／`--ok` 完成与进行、`--offline` 离线。禁止把状态色用于装饰。
- 来源（工程、应用、Agent、分支、任务 ID）不分配色相，统一 `--muted` 加 mono；仅当前选中项可用 `--accent`。禁止为不同工程／应用生成专属色板或随机色。
- 同一颜色不得同时承担状态与来源两种语义；新增来源标识前先确认不与第 4 节色义冲突。
- 颜色不能是唯一信息载体：状态徽标必须带文本标签，色盲用户仅凭文字也能读懂。

## 6. 表格

- 表头 `12px`、`--muted`、左对齐；单元格正文 `13px`、`--text`。
- 行分隔 `1px --line`，行悬停 `--hover`；不使用斑马纹。
- 数字、时间、ID、路径用 mono 并右对齐；工程名、Agent 名保持左对齐并允许省略号截断，悬停显示完整值。
- 表格只允许在内容区横向滚动；页面本身不得横向滚动。空结果走第 8 节空态，不用空白表头占位。

## 7. 表单

- 标签 `12px`、`--muted`，位于控件上方；正文提示 `13px`。
- 控件高 `32px`、圆角 `6px`、底色 `--panel`、边框 `1px --line`；文本与选择值 `13px`。
- 主操作按钮用 `--accent` 填充配 `--accent-ink` 文本；次操作用 `--panel` 底、`--muted` 文本。同一区域只保留一个主操作。
- 校验失败用 `--danger` 文案并通过 `aria-describedby` 关联控件；只读态用 `--muted`，不以禁用外观冒充只读。
- 表单提交中禁用重复提交并保留已填值；不使用阻塞式弹窗确认。

## 8. 空态

- 空态使用 `1px dashed --line`、圆角 `6px`、内边距 `24px 16px`，说明文字 `13px --muted`，最多一句说明加一个可选主操作。
- 泳道空态可附 `17px` mono 符号，符号用 `--faint`，并带 `aria-hidden="true"`。
- 空态不得用大幅插画或渐变背景；错误态例外，错误文案必须用 `--danger` 并说明下一步。

## 9. 抽屉

- 右侧抽屉宽度 `min(500px, 94vw)`，底色 `--panel`，左边界 `1px --line-strong`，遮罩 `--scrim`。
- 头部内边距 `24px`，标题 `18px`／行高 `1.5`；正文内边距 `22px 24px`；区块以 `1px --line` 分隔，上边距 `16px`。
- 实现 `role="dialog"`、`aria-modal="true"`、`aria-labelledby`；打开时背景 `inert`，焦点进入抽屉并循环。
- 关闭方式：右上角按钮、`Esc`、点击遮罩。打开动画 `220ms` 位移，随后内容不重排。

## 10. 焦点与键盘

- 所有可聚焦元素使用 `:focus-visible`，轮廓 `2px --accent`、偏移 `3px`；禁止 `outline: none` 后不给替代。
- 卡片支持点击、`Enter`、`Space` 打开抽屉；`/` 聚焦搜索框；`Esc` 关闭抽屉或退出搜索。
- 焦点顺序与视觉顺序一致；抽屉内焦点不逃逸到背景；关闭后焦点回到触发卡片。
- 图标按钮必须有可访问名称（`aria-label`），不得只靠符号表意。

## 11. 动效与减弱动画

- 交互态过渡 `150ms`，抽屉 `220ms`，页面入场 `300ms`（位移 `5px`），缓动 `cubic-bezier(.2,.8,.2,1)`。
- 只做一次性入场与状态过渡；禁止无限循环动画、视差和自动播放。
- `prefers-reduced-motion: reduce` 下关闭全部动画与过渡（`animation: none !important`、`transition: none !important`），功能不得依赖动画完成。

## 12. 中英双语

- 默认 `zh-CN`；界面语言可切换并持久化。同一页面只出现一种语言，ID、路径、命令保持原样。
- 中英标签成对维护，不机翻拼接；英文用 sentence case，中文不加字距，全大写拉丁标签才允许 `letter-spacing: 1px`。
- 文案不得写死像素宽度，按钮与筛选器可换行或省略；英文文案长度不得撑破 `32px` 控件或 `6px` 圆角容器。
- 时间、数字、任务数用 mono，并按当前语言格式化；中文文案不依赖英文标点，英文文案不残留中文标点。

## 13. 窄屏

- 断点固定 `1500px` / `1100px` / `700px`，与既有 Board 一致，不新增断点。
- `≤1100px`：页面边距 `22px 20px 0`，顶部栏左右 `20px`，泳道间距 `10px`，卡片内边距 `10px`。
- `≤700px`：隐藏侧栏，工程改用筛选器选择；顶部栏 `48px`、左右 `16px`；页面边距 `20px 16px 0`；标题 `20px`，描述 `10px`；搜索框占满整行；泳道 `255px` 横向滚动。
- 任何宽度下都不得出现页面级横向滚动；触摸目标不小于 `32px`。

## 14. 验收与变更

- 验收：`python3 -m unittest discover -s docs/contracts/vnext/ui -p 'test_*.py'`，并保持 `node --test internal/board/page.test.cjs` 通过。
- 改颜色、圆角、字级、间距、状态词汇或泳道，必须新建任务卡并同时更新本契约与实现；只改一边视为漂移。
- 新增页面以本契约为默认样式，不再另写一份设计说明；页面局部差异必须在任务卡里登记并说明理由。
